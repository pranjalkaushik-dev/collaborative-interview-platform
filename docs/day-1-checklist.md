## Branch commands for every member

```powershell
git clone <repository-url>
cd collaborative-interview-platform
git switch main
git pull origin main
git switch -c feature/<your-feature-name>
```

Never work directly on `main`. When a feature is ready, push its branch and create a Pull Request on GitHub.
